## Distribution in this repository
The build-cached files public/assets/avatars/arjun-v4.glb and priya-v4.glb are exact copies of models/arjun_smart.glb and models/priya_casual.glb from Avatar Studio commit 2fd9ec82fbe1613d40ae38aadcca3f410725f740. Embedded outfit textures, animations and the characters in the rendered gallery poster use the same source. The gallery architecture, picture placeholders and ambient melody are generated by the application. The CSS uses system fonts.
